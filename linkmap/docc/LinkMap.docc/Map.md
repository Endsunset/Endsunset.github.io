# Map

The Map is the first screen in LinkMap. It stays visible even before you choose a Project.

Open Dashboard → Context to select a Project, Activity, and optional Assignment. The Map shows the selected Project’s Locations. Selecting an Activity adds its Routes; selecting an Assignment focuses the view on that team’s work.

Tap a Location marker to open its actions, then choose Detail. Use the Map toolbar’s Edit Locations action to add or move places. Save to keep changes or Cancel to discard them.

See <doc:Locations> for the places shown on your Project map.
