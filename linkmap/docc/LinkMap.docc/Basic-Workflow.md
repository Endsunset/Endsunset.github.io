# Basic Workflow

Follow one Project from a first place to a planned visit.

1. From the Map, open Dashboard → Add Project. Give the Project a name.
2. Open Dashboard → Context and select the new Project.
3. Open Dashboard → Current Project. Add the Locations the team needs to visit. Use Regions and Layers if the area has distinct sections or levels.
4. Create an Activity for the upcoming visit. Add a Route using the Project Locations as Stops, then create an Assignment for the person or team following it.
5. Select the Activity and optional Assignment in Context. Return to the Map to follow the route and open Location details.
6. When the work is over, archive the Activity. Keep the Project and its places for the next visit.
