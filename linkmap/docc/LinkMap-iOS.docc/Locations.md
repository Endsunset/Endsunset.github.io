# Locations

Save the places your team needs to find or visit.

A Location can represent an entrance, room, checkpoint, or delivery point. Routes reuse these Project places as Stops.

## Add a Location

1. Open your Project, tap More, then Edit Map.
2. Tap Add, then Location.
3. Tap the map where you want to place the Location.
4. Enter a name and, if useful, a Detail. Choose a Region and Layer if you have created them.
5. Tap Done.
6. Tap Save in the map toolbar to save your changes.

You can add several Locations before saving the map.

## Change a Location

While editing the map, tap a Location marker. Change its name, details, Region, or Layer. Tap Done, review Apply Changes if it appears, then tap Save in the map toolbar.

Changes to an existing Location can affect historical activity logs. Check that you have selected the correct place before continuing.

## Move a Location

1. Open the Location while editing the map.
2. Tap Relocate Location, then tap the new position on the map.
3. Tap Save to accept the position.
4. Tap Done in the Location editor, then Save in the map toolbar.

Cancel during relocation restores its previous position. Cancel in the map toolbar discards the whole map editing session.

## Draw a Location's area

An area shows the space associated with a Location, such as its responsibility or delivery area. You need Project edit permission.

1. Open the Location while editing the Project map.
2. Tap Edit Area to work on its boundary on the map.
3. Tap the map to add boundary vertices. Review the shape as you add them.
4. Use Clear if you need to remove the draft boundary and redraw it.
5. Tap Done in the Location editor and review Apply Changes if it appears.
6. Tap Save in the map toolbar when the map changes are ready.

Cancel discards the map editing session. Review existing Location changes carefully because they can affect historical activity views.

## Delete a Location

Open the Location while editing the map, tap Delete Location, and confirm. Tap Save in the map toolbar when you are ready to save the map changes.

To view a Location without editing, tap its marker on the map. See <doc:Map>.
