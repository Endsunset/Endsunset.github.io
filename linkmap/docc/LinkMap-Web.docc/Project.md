# Project

Choose a Project and browse its saved places and Items.

## Choose a Project

1. Choose Project in the sidebar. The panel is titled Projects.
2. Sign in if requested, then wait for the list to load.
3. Enter part of a name in Find a project if you need to narrow the list.
4. Choose a Project and wait for its map data to load.

The first Project opens automatically when the list loads. Projects are listed newest first. A Shared badge identifies Projects shared with you that you have already accepted. To change Projects, choose another name in the list.

On a phone, choosing a Project closes the panel to reveal the map. Choose Project again to browse its records.

## Browse Project records

Under Browse project, choose Project details to see whether the Project is private or shared and the counts of its Locations, Regions, Layers, and Items. Choose a count to open that list.

You can also open Locations, Regions, Layers, or Items directly under Browse project. Choose a record to inspect it. Back returns through related details, and Close details closes the panel. You can continue using the map while details are open.

See <doc:Locations>, <doc:Regions-and-Layers>, and <doc:Items> for the information available in each list.

## Create, edit, or share a Project

Use LinkMap for iOS to create, rename, edit, delete, or share a Project and to accept invitations. The web app only displays Projects your signed-in account can access; it has no permission-management or invitation-acceptance controls.

After a change in iOS, use Refresh map data for the selected Project, or reload the page to update the Projects list. See <doc:iCloud> if a Project is missing or cannot load.
