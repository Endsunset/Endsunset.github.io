# iCloud

Sign in to view your private and accepted shared Projects in the web app.

## Sign in with your Apple Account

1. [Open the Web App](https://endsunset.github.io/linkmap/app/) and choose Project.
2. Choose Sign in when it appears.
3. Complete Apple's sign-in using the Apple Account you use for LinkMap. Apple handles your credentials.
4. When you return to the map, wait for your Projects to load.

Web sign-in is separate from the account signed in on your iPhone or iPad. Search Maps remains available without signing in to iCloud.

Your account must have access to a Project to load it. Accept Project invitations in LinkMap for iOS before opening the shared Project on the web. Sharing and editing permissions are managed in iOS; all web Project viewing is read-only.

## Refresh saved information

1. Finish saving your changes in LinkMap for iOS.
2. In the web app, choose Project and select the Project you want to update.
3. Choose Refresh map data and wait for the records to finish loading before opening details.

Refresh map data reloads the selected Project's Locations, Regions, Layers, and Items. To update the Projects list after creating a Project or accepting an invitation, reload the page. Refreshing or changing Projects closes the open Project details.

## If a Project is missing

Check that you signed in with the same Apple Account used for LinkMap, clear Find a project, and reload the page. If the list is empty, create a Project or accept a Project share in the iOS app first.

For a shared Project, check with its owner that your access is still available. An Activity invitation is separate from Project access; the web app does not display Activities.

## Recover a failed load

1. Read the displayed error and check your internet connection.
2. Choose Try again in the Project panel when available. It retries the connection, Project list, or selected Project load that failed.
3. If signing in fails, use Try again on the sign-in page. Account also offers Retry sign-in check when the account check fails.
4. Reload the page if the problem continues, then check your account and Project access in iOS.

A failed Project load is not an empty Project. The web app clears the previous Project's map and details while loading and shows a retry state if it cannot load the records. There are no web edits or save drafts to recover. Reopen the Project's details after a successful load.

## Manage your session

While signed in, choose Project → Account to check your Apple Account session and use Apple's sign-out control. Use Back to LinkMap to return to the map.

Signing out removes Project access from the web view. To manage or delete Project data, use LinkMap for iOS. See the [privacy policy](https://endsunset.github.io/linkmap/privacy-policy/) for storage, sharing, and deletion details.
