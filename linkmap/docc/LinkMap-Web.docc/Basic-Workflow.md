# Basic Workflow

Find a place, open a Project, and inspect a saved Location in LinkMap for Web.

## Find a place

1. [Open the Web App](https://endsunset.github.io/linkmap/app/) and choose Search.
2. Enter a place name or address in Search Maps.
3. Choose a suggestion to open its place details. Alternatively, press Enter or choose the Search Maps button, then choose a result.

You can do this without signing in. See <doc:Map> for more search and navigation options.

## Open your Project

1. Choose Project in the sidebar.
2. If Sign in appears, choose it and complete Apple's sign-in using the account you use for LinkMap. You return to the map after signing in.
3. Wait for the Projects list, then choose your Project. Use Find a project to filter the list by name.
4. Wait for the Project's records to load, then choose Locations under Browse project.

If you have no Projects, create one or accept a Project invitation in LinkMap for iOS, then reload the web app. See <doc:iCloud> if loading fails.

## Inspect a Location

1. Choose a Location from the list to open its saved details.
2. Review About, coordinates, and any Region or Layer links that are available.
3. Choose Show on map to center on its saved coordinate, or Directions to open Apple Maps directions in a new tab.
4. Choose Back to return to the list, or Close details to leave the map visible.

You can also select a Location marker directly on the map. Locations without valid coordinates remain in the list but have no Show on map or Directions action. See <doc:Locations>.

## Load later changes

After editing the Project in iOS, choose Project → Refresh map data in the web app. Browsing is read-only, so there is no Save step in the web app. See <doc:iCloud> for refreshing the Project list and recovering a failed load.
