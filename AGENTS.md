# Repository instructions

## Commit and push by default

Unless the user explicitly instructs otherwise, automatically commit and push completed changes to the current branch's remote after running the checks appropriate to the task. Do not ask for additional confirmation before committing or pushing.

- Include only changes belonging to the task, including work completed earlier in the same conversation. Leave unrelated user changes untouched.
- Use a concise commit message describing the changes.
- Use a normal push; do not force-push or rewrite published history unless explicitly requested.
- If a check, commit, or push fails, resolve it when safe and within scope. Otherwise, report the blocker accurately; never claim an unsuccessful push succeeded.
