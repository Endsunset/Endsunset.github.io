# Basic Workflow

Create a small Project and plan your first visit in LinkMap for iOS.

## Create a Project and add places

1. Tap Projects at the upper left of the map.
2. Tap the Project Actions button (the ellipsis), then Add Project.
3. Enter a name and tap Save.
4. In the Project's Console, tap More, then Edit Map.
5. Tap Add, choose Location, then tap the map to place it.
6. Enter a name and any details, then tap Done. Repeat for the other places you need.
7. Tap Save in the map toolbar to save the Project map.

See <doc:Locations> to move a place or change its details.

## Prepare the visit

1. Open Activities from your Project.
2. Tap Activity Actions (the ellipsis), then Add Activity. Enter a name, leave Copy set to None, and tap Save.
3. Open Routes and tap Add Route. Select the places to visit on the map, then tap Next.
4. Name the Route. Tap Edit to arrange Location Order, then tap Save.
5. Open Assignments, tap the plus button, enter a name, and select the Route. Tap Save.

You can add more Routes and Assignments before starting. See <doc:Activities> to reuse a previous plan.

## Start and follow the work

The Project owner opens the Activity's More menu, taps Start, and confirms. Starting locks the plan and renews Activity sharing. If you are working with others, send the new Activity invitation after starting; see <doc:Sharing>.

In the active Activity, open Assignments, choose your Assignment, then open Routes and choose a Route. The map follows the work you open in the Console.

When the work is finished, save any Route work. The owner can tap More, then End Activity, and confirm End. Ending preserves the history and removes existing collaborators' access to the Activity. It cannot be undone.
