# Regions and Layers

Group nearby places and organize levels within your Project.

A Region groups Locations in an area, such as a building. A Layer groups Locations at a level within that Region, such as a floor. Each Location can belong to one Region and one Layer.

## Add a Region

1. Open your Project, tap More, then Edit Map.
2. Tap Add, then Region.
3. Select the Locations for the Region on the map, then tap Add Region.
4. Enter a name and tap Done.
5. Tap Save in the map toolbar.

Available Locations appear red, selected Locations blue, and unavailable Locations grey. A Location already in another Region cannot be selected for this Region.

## Add a Layer

1. While editing the map, tap Filter and choose All or Region. Tap the Region's purple marker to open its editor.
2. Tap Add Layer.
3. Enter a name and choose a Level. Use a unique, nonzero number within the Region; zero is reserved for the base map.
4. Tap Select Locations, then choose the places on the map. Grey Locations are unavailable, including places already in another Layer.
5. Tap Save to accept the selection, then Done in the Layer editor.
6. Tap Done in the Region editor, then Save in the map toolbar.

You can also assign a Location to a Region and Layer in its Location editor. See <doc:Locations>.

## Change a Region or Layer

You need permission to edit the Project.

1. Open Edit Map and tap the Region marker to open its editor.
2. Change the Region name or use Select Locations to adjust its places.
3. Open a Layer to change its name, Level, or selected Locations. Keep its Level unique and nonzero within the Region.
4. Tap Done in each editor, review Apply Changes for existing records, then Save in the map toolbar.

Locations unavailable for that Region or Layer remain grey. Moving a Location to another Region can require choosing a different Layer as well. Cancel in the map toolbar discards the editing session.

## Show a Layer on the map

Move the center of the map into a Layer's area to show the Layer selector. Choose a Layer to see that level, or choose Map to return to the base map. A Layer's outline comes from its Locations.
