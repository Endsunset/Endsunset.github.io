# Map

Search Apple Maps and explore saved Project places without changing them.

## Find a place or address

1. Choose Search in the sidebar.
2. Enter a place name or address in Search Maps.
3. Choose a suggestion to open the first matching place. To see a list of results instead, press Enter or choose the Search Maps button.
4. Choose a result to show it on the map and open Place details.

Search works without signing in to iCloud and looks for Apple Maps places, rather than saved Project records. To find a saved Location, use Project → Locations. Selecting a search result does not save a Location.

You can also select an Apple Maps place directly on the map to open its details. Opening an Apple Maps place reveals Search and closes any Project detail panel. Changing Projects leaves your selected Apple Maps place available.

## Explore the Project map

1. Choose Project and select a Project.
2. Wait for its records to load. The map displays the available ground-level places.
3. Pan or zoom to explore, then select a Location marker to open its saved details.

Saved Location areas appear as outlines where available. The map stays at level 0: it shows Locations without a Layer and Locations in level-zero Layers. Higher and lower levels remain available in lists, but opening a Location or Layer does not change the displayed level. See <doc:Regions-and-Layers>.

## Make room for the map

Search and Project each open a panel over the map. Choose the active sidebar button again to close its panel, or choose the other button to switch panels. Collapse sidebar reduces navigation to icons; Expand sidebar restores the labels. Help remains available and opens the web guide in a new tab.

On a wide screen, Project details open beside the sidebar. On narrower screens they use the panel space, and on phones they appear at the bottom of the map. Close details when you want more map space.

## If search or maps cannot load

Keep JavaScript enabled and check your internet connection. Wait for Apple Maps to finish loading before searching. If Search unavailable appears, try the search again. If additional place details are unavailable, select the result again to retry.

Reload the page if the map still cannot load. For Project-loading problems, see <doc:iCloud>.
