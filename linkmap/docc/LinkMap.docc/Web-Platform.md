# LinkMap for Web

Open LinkMap in a browser to explore places and view your Project map.

## Open the web map

Go to the [LinkMap web map](https://endsunset.github.io/linkmap/app/). There is no app to install. You can search for places and inspect coordinates without signing in. To view your own or shared Projects, sign in with the Apple Account you use for LinkMap.

### Sign in to view your Projects

1. Choose Sign in on the web map.
2. Sign in with the same Apple Account you use for LinkMap on iOS. This is a separate browser sign-in, even if you already use the iOS app.
3. Use the Project selector above the map to choose a Project you own or have joined.

The selected Project's Locations appear on the map. Choose a Location to inspect it. You can switch Projects without signing in again.

If a shared Project is missing, check that you accepted its invitation in the iOS app, then load the web map again. If a Project has no visible Locations, add places in the iOS app and reload the web map.

### Find a place or address

Type a place or address in Search and choose a suggestion or result. The map moves to the selected place and shows its details when available. Your Project Locations remain available when you change the search selection.

### Show and copy coordinates

Enter a latitude and longitude pair in Coordinates, then choose Show on map. For example, enter `37.3349, -122.0090`. Choose Copy to share the coordinate text.

### Continue planning on iOS

Use the iOS app to create Projects, add or edit Locations, plan Activities and Routes, and manage sharing. See <doc:iOS-Platform> to get started.
