# Routes and Stops

Put the places to visit in order for an Activity.

Each Stop uses a Location from the Project. Prepare Routes while the Activity is in Planning and you have permission to edit it.

## Create a Route

1. Open the Planning Activity, then Routes.
2. Tap Add Route.
3. Select Locations on the map, then tap Next.
4. Enter a Route name.
5. Tap Edit to rearrange Location Order.
6. Tap Save.

Tap Select Locations if you need to change the selection before saving. Tap Cancel to discard the Route edit.

## Choose available Locations

During selection, red Locations are available, blue Locations are selected, and grey Locations are unavailable. Tap a selected Location to remove it from the selection.

A Location already used by another Route in the same Activity remains visible in grey and cannot be selected. A Location can appear only once in a Route.

## Give a Route to a team

Create an Assignment and choose its Routes. A Route can belong to one Assignment. See <doc:Assignments>.

## Follow a Route

In an active Activity, open Assignments, choose your Assignment, then open Routes and choose a Route. Read its Stops in order and tap Location markers to see place details on the map.

Starting the Activity locks its planned Routes and Assignments. Complete any changes to the plan before starting; see <doc:Activities>.
