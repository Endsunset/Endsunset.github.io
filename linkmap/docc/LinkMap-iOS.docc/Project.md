# Project

Keep the places, reusable Items, and Activities for one area together in a Project.

## Create a Project

1. Tap Projects at the upper left of the map.
2. Tap Project Actions (the ellipsis), then Add Project.
3. Enter a name, then tap Save.

The Project opens in the Console. Add places with <doc:Locations>, or open Activities to plan work.

## Open another Project

Tap Projects, then tap the Project you want to use. Enter a name in Search Projects to find it in the list.

The Console shows the open Project. Activities opens its work, Items opens its reusable resource definitions, and Project Map opens its map tools. Recently opened Projects appear first. Pull down the Projects list to refresh it.

To return to the map without changing Projects, tap the exposed map strip beside the list or drag that strip left. Back in the Console returns through Route → Assignment → Activity → Project.

## Change the Project name

If you own the Project, open its More menu and tap Name. Enter the new name, then tap Save.

## Edit the Project map

Open the Project's More menu and tap Edit Map. You need permission to edit the Project. Add or change Locations, Regions, and Layers, then tap Save in the map toolbar. Tap Cancel there to discard the map editing session.

Project map changes also affect the places used by existing Activities. Review the Apply Changes prompt when editing an existing place.

## Use Project Map tools

1. Open Project Map from the Project's Console.
2. Use Location List to browse places, or Regions and Layers to inspect their organization.
3. Use Edit Locations when you have Project edit permission.
4. Use Refresh Map Data to reload the Project's places.

When there is a current Activity with Route paths, Shortest Path Display changes how its paths are displayed. This does not rearrange saved Stops. See <doc:Map> and <doc:Routes-and-Stops>.

## Share a Project

The owner's More menu includes Share. Project sharing covers the map and Item definitions; share each Activity separately for its work. See <doc:Sharing> for invitations and permissions.

## Leave a shared Project

If you joined someone else's Project:

1. Open the Project's More menu.
2. Tap Leave Project.
3. Review the confirmation, then choose Leave Project to continue or Cancel to keep your access.

Leaving removes your access to the Project and its shared Activities. The Project and its data remain available to the owner and other participants. Ask the owner for invitations if you need to join again.
