# Settings and Imports

Manage report preferences and caches, or bring Locations from an existing LinkMap document into a Project.

## Open Settings

1. Tap Projects at the upper left of the map.
2. Tap Settings (the gear button).
3. Choose Cache, Report Style, Import, Documentation, or Credits.
4. Use Close Settings to return to Projects when you finish.

See <doc:Results-and-Reports> for report templates, separators, language, and preview controls.

## Import Locations

Import reads Locations from a compatible LinkMap document. It does not restore a complete Project with Activities, Items, or transfer history.

1. Create or join the destination Project first, and make sure you can edit it.
2. Open Settings and tap Import to open the document browser.
3. Choose the LinkMap document containing the places you want to bring in.
4. When Upload Locations appears, choose the destination Project. This uploads the locally imported Locations to that Project. Tap Skip if you do not want to upload them now.
5. Open the Project and check its Locations on the map.

The upload creates new Project Locations. If an upload fails partway through, inspect the destination before trying again so you can identify places already added. An empty document provides no Locations to upload. Create or join a Project if the destination list is empty.

LinkMap can also open ZIP documents for extraction. Opening an archive alone does not import its contents as Project data; open the compatible LinkMap document inside when importing Locations.

## Clean caches

1. Open Settings → Cache and check Cache Size.
2. Choose Clean App Cache or Clean Cloud Cache for that cache, or Clean All Cache for all cached files.
3. For Clean All Cache, review the confirmation and tap Clean to continue, or Cancel to keep the files.

Cache cleanup cannot be undone. Finish pending work first. Use the Project and sharing controls to manage saved data and access; cache cleanup is not a way to leave a shared Project. See <doc:Project> and <doc:iCloud>.

## Get help

Documentation opens this guide. Credits lists acknowledgements. If information fails to load or save, follow the app's error message and the recovery steps in <doc:iCloud> before repeating the action.
