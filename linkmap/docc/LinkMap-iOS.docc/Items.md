# Items

Define the resources your team supplies and distributes during Activities.

An Item is a reusable name in a Project, such as Water bottle or Meal pack. Creating an Item does not add stock. Record Supply in an active Activity to add a quantity, then transfer it to an Assignment for delivery. See <doc:Item-Transfers>.

## Create an Item

You need permission to edit the Project. Item definitions remain available across its Activities, regardless of Activity state.

1. Open the Project in the Console, then tap Items.
2. Tap Add Item (the plus button).
3. Enter the Item name. Use a name that makes its counting unit clear, such as Water bottle rather than Water.
4. Tap Save and review Save Item Permanently?.
5. Check the name, then tap Save Anyway to create it, or Cancel to return to the draft.

Saved Item fields cannot be edited. Check spelling and units before confirming. An empty name uses the app's New Item fallback.

## View an Item

Open Project → Items and select an Item to read its saved name. Quantities belong to Activities and Assignments; the Items list is the Project's catalog of definitions.

## Use Items in an Activity

1. Prepare the Activity's Routes and Assignments while it is in Planning.
2. Ask the Project owner to start the Activity.
3. Open the active Activity and tap Record Item Transfers to record Supply and allocations.
4. Open an Assignment to check its Resources, record returns or transfers, and follow its Routes to distribute Items at Stops.

Resource entry and Stop distribution require edit access to the active Activity. Creating an Item requires Project edit access; these permissions are separate. See <doc:Sharing>.

## If no Items or resources appear

No Items means the Project has no loaded Item definitions. Ask someone with Project edit access to create them. No Resources at an Activity or Assignment can mean no quantity has been recorded there yet. Supply goes to the Activity before it is transferred to an Assignment.
