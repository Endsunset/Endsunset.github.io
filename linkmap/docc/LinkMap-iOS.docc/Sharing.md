# Sharing

Invite people to your Project map and the Activities they need.

Project and Activity invitations are separate. Project permissions control access to the map; Activity permissions control access to that round of work. Sharing one does not automatically share the other.

## Share a Project

If you own the Project:

1. Open the Project's More menu, then tap Share.
2. Tap Start Sharing if you have not shared it before.
3. In the sharing controls, choose who can join and whether they can view or edit.
4. Send the invitation to your collaborators.

After sharing has been set up, tap Control to manage access. A QR code is available when access by link is enabled.

## Share an Activity

1. Share the Project first and ask collaborators to accept that invitation.
2. Open the Activity's More menu, then Share.
3. Tap Start Sharing if needed, choose permissions, and send the Activity invitation.

The owner can allow viewing or editing during Planning and Active. Planning edit access allows setup changes; Active edit access allows Item transfers and Stop updates. Ended Activities support viewing only.

Starting or ending an Activity revokes its current invitation and removes previous participants. It does not automatically create a new invitation. Open Share → Start Sharing again, then send the new invitation for the new state. Project sharing is unchanged.

## Accept an invitation

Open the invitation on a device with LinkMap installed. Accept the Project invitation before the Activity invitation.

To scan a QR invitation, tap Projects, open Project Actions (the ellipsis), then tap Scan. Activities also has a Scan action in Activity Actions. Allow camera access when prompted; if it was denied, enable it in device Settings or use the invitation link instead.

After joining, choose the shared Project in Projects and open the Activity you were invited to.

## If shared work is unavailable

Check that you are using the Apple Account that received the invitation and that you accepted both invitations when an Activity needs Project access. Ask the owner for a current Activity invitation if the Activity has just started.

Ending an Activity removes existing collaborators' access. The owner can share its history again with view-only permissions.

If you can read work but cannot change it, check both its current state and your invitation's edit permission. Project edit access covers Locations and Item definitions; Activity edit access covers that Activity's allowed work. Only the Project owner can create Activities or change their state.
